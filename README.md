# hagedornworks

Static website for Hagedorn Works, served via GitHub Pages at https://hagedornworks.se

- `/grid9/privacy/` – Privacy Policy for Grid9 Sudoku
- `/grid9/terms/` – Terms of Use
- `/grid9/support/` – Support

The pages are plain HTML + one stylesheet (`assets/site.css`), no external requests.
`build_pages.py` generates the HTML (`python build_pages.py`); edit text there and re-run,
or edit the HTML directly. URLs given to Apple must not change.
